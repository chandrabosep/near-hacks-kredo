# Charging

Two ways to take credits: charge right away, or hold first and charge what the work actually cost.

## Charge

For anything quick. Charge by action, using your price list, or by an amount:

```ts
await credits.charge({ user, action: "chat.message", ref: messageId });
await credits.charge({ user, action: "video.render", quantity: 12, ref: jobId }); // 12 seconds
await credits.charge({ user, credits: 5, ref: orderId });
```

The charge settles on Whitechain before the call returns, and the result includes the transaction.

## Hold and capture

For long or uncertain work, hold the most it could cost. The price is locked when you hold.

```ts
const hold = await credits.hold({ user, action: "video.render", quantity: 12, ref: jobId });
try {
  const seconds = await render(job);
  await credits.capture(hold.holdId, { credits: seconds * 6 }); // the rest goes back
} catch {
  await credits.release(hold.holdId); // the user keeps everything
}
```

- `capture(holdId)` with no amount charges the whole hold.
- You can't capture more than you held.
- Holds expire after an hour unless you pass `ttlSeconds`. Expired holds are released automatically.

## Refunds

Give credits back, up to what the user spent with your app:

```ts
await credits.refund({ user, credits: 5, ref: `refund-${orderId}` });
```

Refunds come out of your unpaid earnings. You can also refund any charge from the dashboard's activity table.

## Refs and retries

Every write takes a `ref`: your own id for the operation, such as a message or order id. The same ref always returns the first result, so retrying after a timeout can never charge twice. If you leave it out, the SDK makes one.

The SDK retries network failures and rate limits for you, with the same ref.

## Quotes

Show a price before charging:

```ts
const q = await credits.quote({ action: "video.render", quantity: 12 });
// { label: "12 seconds", price, networkFee, youEarn }, each as { credits, usd, units }
```

## Light mode

If you keep your own credits, set how many of ours buy one of yours, then convert when a user buys:

```ts
await credits.setExchangeRate(2); // 2 of our credits per 1 of yours
const c = await credits.convert({ user, credits: 20, ref: orderId });
// c.appCredits === "10": add 10 of your own credits to the user
```
