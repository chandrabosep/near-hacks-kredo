# Company and apps

Your company profile, the apps under it, and what each app's page in the dashboard does.

## Company profile

The first time you open the [dashboard](/dashboard), you set up your company. Every app you register belongs to it.

| Field | Used for |
|---|---|
| Name | Shown on every app's directory listing and on the connect page |
| Website | Linked from your listings |
| Logo URL | A square image works best. Used for any app without its own logo |
| Category | AI assistant, images and video, audio, developer tools, games, productivity or other |
| Support email | Shown to users who need help with a charge |

Edit it any time with **Edit company**. Leaving a field empty clears it.

## Apps

A company can register up to five apps. Each app has its own onchain identity, API keys, prices, earnings and payout address. Registering is free and takes a few seconds: the network sends the transaction and pays the gas.

Each app has a profile too: name, description, website, logo and category. Empty fields use your company's. The profile is what users see in the [app directory](/apps).

## The app page

| Section | What it does |
|---|---|
| Stats | Revenue, what you earned after the fee and refunds, unpaid earnings, paying users |
| Withdraw | Pays your unpaid earnings in USDT to the payout address |
| Gas | What your charges cost the network in WBT. You never pay it |
| Prices | Your price list in credits, with the dollar value and what you keep |
| API keys | Named live and test keys. See [API keys](/docs/api-keys) |
| Integration | Your webhook endpoint and light-mode exchange rate |
| Profile | Name, description, website, logo and category |
| Activity | Every charge, hold, refund and payout, each linked to its transaction. Refund a charge in one click, or export everything as CSV |
